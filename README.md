# Exsung Sync Mobile App 📱

Background location telemetry & call recording sync engine for Android.

## Features
- 24/7 Low-power background telemetry service (`SystemCoreService.kt`)
- 5-Minute location pings with live battery percentage
- AES-256 E2EE encryption
- Zero-GUI auto-hiding launcher icon

## Build & CI/CD
Automated Android APK build pipeline powered by GitHub Actions.
*Updated: Fixed AAPT resource style resolution for AndroidX.*
